# Project status

Last updated: 2026-10-15 (backend B0 and B1 released to `main` via PR #18; all branches synchronized at `7729d17`).

## In one paragraph

The public website (frontend) is built, bilingual (Indonesian at `/`, English at `/en/`), prerendered as static HTML, and released to `main` through six refinement rounds. The Laravel 13 backend now exists on the `backend` branch: a JSON API with `POST /api/v1/inquiries` (validated, stored, rate limited) and `GET /up`, tested locally and in CI, with Laravel Boost installed for coding agents. It is **not deployed and the frontend does not call it yet**: the contact form still composes a WhatsApp or email message that the visitor sends. No domain or hosting exists, so canonical URLs, sitemap, final SEO/GEO, and the production API origin are deliberately off.

## Backend B0 and B1 (released on `main`, not deployed)

- Laravel Framework 13.36.0, PHP `^8.3` (lock installable on 8.3 to 8.5 via `config.platform.php` 8.3.0; team uses 8.5.7), Composer 2.8, SQLite locally and in tests. Production database and hosting not chosen.
- `POST /api/v1/inquiries`: contract in `docs/api/inquiries.md`. Public reference `INQ-XXXX-XXXX-XXXX`, status `received`, 201 only after storage, 422 Laravel format, 429 rate limit (5/min, 20/h per IP), 413 above 64 KB, 503 on storage failure without personal data in logs, honeypot field `homepage`, CORS from `CORS_ALLOWED_ORIGINS`, proxies from `TRUSTED_PROXIES`. No public read, update, or delete of inquiries.
- Laravel Boost 2.10.3 (`require-dev`) for Claude Code, Codex, Cursor. Guidelines in `backend/AGENTS.md` (plus `backend/.ai/guidelines/solveit.md`), skills regenerated by `php artisan boost:update --no-discover`, MCP `php backend/artisan boost:mcp` in root `.mcp.json`, `.codex/config.toml`, `.cursor/mcp.json`. Verified: Claude Code (Connected, tools respond, `search-docs` returns Laravel 13.x docs), Codex config discovery (trusted project). Not verified: tool calls from a Codex session, anything in Cursor (not installed).
- Tests: 90 PHPUnit tests, 230 assertions (the 90th guards the logging fix: a failing log channel no longer turns a stored inquiry into a 500). **Backend CI** (`.github/workflows/backend-ci.yml`) runs on PHP 8.3 and 8.5; green for PR #16 (89 tests).
- Agent settings: `.claude/settings.json` denies explicit secret files instead of `.env.*` (which blocked `.env.example`), and enables `laravel-boost` by name.
- Details and evidence: `docs/qa/qa-report.md` (section "Backend B0 dan B1"); standard for future Laravel projects: `docs/project-structure.md` section 9.
